## MediaKits

MediaKits is a platform that allows creators to connect their social media accounts and display their analytics insights on a customizable landing page or media kit.

**Description:**
MediaKits aggregates social media analytics from multiple platforms like Instagram, YouTube, TikTok, Twitter (X), etc. into a centralized dashboard. Creators can then showcase these analytics in a visually appealing and professional media kit or landing page, designed to be easily shareable with others.

**Main Features:**

- Connect and aggregate analytics from multiple social media platforms like Youtube,Facebook,Instagram,Twitter and Tiktok
- Customizable media kit templates with branding options
- Custom URLs for easy sharing
- Custom widgets to highlight specific metrics
- Talent rosters with cohort-wide analytics for multi-creator teams/agencies
- Daily updated live stats integrated into media kits and so on [refer to reference]

**Workflow:**

1. Create an account on the MediaKits website
2. Add a new media kit and connect your social media accounts
3. Navigate to the dashboard 
4. Customize the template with your branding and edit fields on the landing page
5. Choose the metrics and analytics you want to display
6. Generate a custom URL for your media kit
7. Share the media kit URL with others
